# 효과음 출처·라이선스 (FUNC-005-14)

저작권 문제가 없는 리소스(직접 제작 또는 CC0 등)만 넣고, 파일마다 아래 표에 기록한다.

| 파일 | 용도 | 출처 | 라이선스 |
|---|---|---|---|
| `bell.wav` | 종 누르기(누르는 즉시) | 직접 제작 — `client/scripts/generate-sounds.mjs`로 합성 | 프로젝트 자체 제작물(외부 리소스 없음) |
| `card.wav` | 카드 내기·서버 자동 내기 | 직접 제작 — 같은 스크립트 | 프로젝트 자체 제작물 |
| `success.wav` | 종 판정 성공(카드 획득) | 직접 제작 — 같은 스크립트 | 프로젝트 자체 제작물 |
| `misfire.wav` | 오발 벌칙 | 직접 제작 — 같은 스크립트 | 프로젝트 자체 제작물 |
| `end.wav` | 게임 종료 | 직접 제작 — 같은 스크립트 | 프로젝트 자체 제작물 |
